# UpMark — Social Audience, Campaign & Order Risk Intelligence

UpMark is a data-driven intelligence project for Pakistani fashion and perfume brands. It brings together product catalogs, social-media activity, customer interactions, and order history to explore audience behavior, campaign performance, product demand, and order-related insights.

The project combines data ingestion, multilingual text processing, NLP/ML analysis, analytical storage, scalability benchmarking, and an interactive Streamlit dashboard.

## Key Features

- Product catalog collection from configured public Shopify JSON endpoints.
- Social posts and interaction ingestion through an Apify-based workflow.
- Multilingual analysis focused on English, Roman Urdu, and Urdu.
- Roman Urdu spelling canonicalization and keyword-based topic/intent categorization.
- Campaign, brand, platform, engagement, and audience analysis.
- DuckDB analytical storage with Bronze, Silver, and Gold data layers.
- Interactive Streamlit dashboard with filters and visualizations.
- Big Data/scalability benchmark workflow.

## Pipeline

Run the scripts in this order:

| Step | Script | Purpose |
|---|---|---|
| 1 | `step1_scrape_catalogs.py` | Collect product catalog data from configured brands. |
| 2 | `step2_scrape_social_apify.py` | Ingest social posts and interactions using the Apify workflow. |
| 3 | `step3_pipeline_nlp_ml.py` | Process data and perform NLP/ML analysis. |
| 4 | `step4_bigdata_benchmark.py` | Run scalability/Big Data benchmarks. |
| 5 | `app.py` | Launch the Streamlit dashboard. |

## Getting Started

### 1. Clone

```bash
git clone https://github.com/tayyaba63/big_data_project.git
cd big_data_project
```

### 2. Create a virtual environment (Windows PowerShell)

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure

Review `config.py` for data paths and configured brand sources. Set up any required Apify credentials/actor inputs locally. **Never commit API tokens, passwords, or private data.**

### 5. Run the pipeline

```bash
python step1_scrape_catalogs.py
python step2_scrape_social_apify.py
python step3_pipeline_nlp_ml.py
python step4_bigdata_benchmark.py
```

### 6. Run the dashboard

```bash
streamlit run app.py
```

The dashboard requires the DuckDB database and Gold-layer outputs generated by the pipeline.
